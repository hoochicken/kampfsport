wir schrieben zusammen ein Buch über kampfsport

* Grosskapitel EInleitung, verschiedene Kapitel
* Kapitel EInleitung (Zusammenfassung), Eigentlicher Inhalt, Merkspruch, Konkrete Übungen
* ein Kapitel umfasst mehrere Abschnitte
* jeder Abschnitt passt auf eine Doppelseite, links Text, rechts Bilder mit (minimalen) Erklärungen
* jeder abschnitt besteht aus Unterabschnitten

Ja, das ist extrem wenig Platz; aus jedem Kapitel könnte man ein eigenes Buch machen.
Es wird alles beinhalten, was ich weiss.

Die Strukturierung der Kapitel ist bereits fertig.

Bitte formuliere den folgenden Abschnitt für unser Kampfsportbuch nach diesen Regeln:

- Ausgabe immer als Markdown
- Keine horizontalen Trennlinien / keine "---"
- Struktur:
  - # für Abschnittstitel
  - ## für Einleitung, Merkspruch, Übungen
  - ### für Unterabschnitte / Kampfstellungen / Techniken
- Keine Überschrift Ebene 4 verwenden
- Kurze, direkte Sprache
- Sachlich und praktisch formulieren
- Keine langen Erklärungen
- Jeder Unterabschnitt besteht aus:
  1. Beschreibung der Position / Technik
  2. Beschreibung der Vorteile
  3. Optional: Nachteile oder Besonderheiten
- Fliesstext statt zu vieler Aufzählungen
- Nur wichtige Begriffe aufzählen
- Stil eines kompakten Trainingshandbuchs
- Jeder Abschnitt muss auf eine Doppelseite passen
- Platz ist extrem begrenzt
- Fokus auf praktische Anwendbarkeit
- Keine Wiederholungen
- Keine philosophischen Texte
- Keine Einleitungen ausserhalb der gewünschten Struktur

Formatbeispiel:

### Frontale Kampfstellung

Der Körper steht frontal zum Gegner. Beide Schultern und die Hüfte zeigen nach vorne. Die Füße stehen etwa schulterbreit auseinander. Das Gewicht ist gleichmäßig verteilt, die Hände schützen Kopf und Oberkörper.

Die frontale Stellung ermöglicht schnelle und direkte Angriffe nach vorne. Besonders geeignet sind: Frontkicks, Gerade Fauststöße. Durch die frontale Körperausrichtung können beide Seiten gleichermassen eingesetzt werden.

Die frontale Kampfstellung präsentiert eine große Trefferfläche. Brust und Bauch sind leichter angreifbar als in seitlichen Positionen.
